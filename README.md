# ⚡ TeslaSim — 3D Интерактивная симуляция Tesla Roadster

**TeslaSim** — это веб-платформа для интерактивной симуляции электромобиля Tesla Roadster. Пользователь может управлять виртуальной машиной в 3D-пространстве: разгоняться, тормозить, рулить, следить за расходом батареи и любоваться открывающимся видом на дорогу и природу.

Проект разработан в рамках учебной практики (ПМ.05) по специальности 09.02.07 «Информационные системы и программирование».

## 🌟 Основные возможности
*   **3D-визуализация**: Модель автомобиля на дороге с эффектом движения (деревья и разметка летят навстречу).
*   **Реалистичная физика (упрощенная)**: Разгон, торможение, расход заряда батареи в зависимости от скорости и режима езды.
*   **Панель управления**: Кнопки газа и тормоза, а также интерактивное руление (влево/вправо).
*   **Телеметрия**: Отображение текущей скорости, процента заряда батареи, запаса хода и общего пробега в реальном времени.
*   **Сохранение прогресса**: Все данные о поездках и состоянии машины сохраняются в базе данных PostgreSQL.

| Слой | Технологии |

| **Frontend** | HTML5, CSS3, JavaScript (Fetch API) |
| **3D-графика** | Three.js (WebGL) |
| **Тестирование** | Pytest |
| **Контейнеризация** | Docker, docker-compose |
